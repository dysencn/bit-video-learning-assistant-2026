# 知学知识图谱实施与验收

首版在《Python 程序设计入门》的一个教学班演示教师确认的先修关系、材料出处、练习和复习反馈。已有的六个课程知识点可直接使用。空课程可通过「课程题库 → 手动创建单选题」建立知识点。

## 数据和接口

- `GET /api/courses/{course_id}/knowledge-graph` 返回当前已保存的先修关系、来源和节点统计。学生获得本人的复习安排，任课教师获得有效名单内学生的汇总。
- `PUT /api/courses/{course_id}/knowledge-graph` 由任课教师提交 `revision`、`prerequisites` 和 `evidence`。先修边包含 `before` 与 `after`。材料关联包含 `knowledge_point_id`、`resource_id` 和可选的 `page`。课件时间取自视频任务中的对应页。保存时校验本班引用、重复、循环和版本冲突。
- AI 导入接口 `POST /api/courses/{course_id}/questions/import-ai` 接受可选的 `knowledge_point_ids`，键为本次勾选的原题 ID，值为目标班级知识点 ID。重复导入保留原题库记录，可在题库中修改已有题目的标签。
- 错题列表和 CSV 支持按 `course_id` 与 `knowledge_point_id` 查询，原有按名称筛选仍可使用。新写入的复习事件以当时的错题知识点作为统计依据。

数据继续保存到本地 JSON。已有课程可直接读取图谱入口。教学班复制时重新映射图谱的知识点与资料 ID，学生名单、提交和复习数据保持各班独立。

## 课堂演示

1. 用隔离数据启动。在视频工作台上传一段与 Python 入门课相符的短视频，完成提取并准备 AI 题目。现场可复用已保存的产物。在课程的「章节与资料」中把课件发布到测试教学班。
2. 打开教师端「学习顺序」，添加至少两条先修关系，为「条件与循环」关联一份讲义和一个课件页。确认保存后刷新，检查箭头、页码和截图时间。
3. 从「AI 出题与分析」或视频 AI 练习页导题，给一道经审核的题选择「条件与循环」。用班内学生账号打开课程图谱，点击该节点进入课件页和章节练习。答错该题后检查错题归档和下次复习时间。
4. 按常规排程在题目到期后进行复习。需要现场演示复习时，可提前准备同一教学班已到期的错题。学生完成复习后刷新图谱，查看复习次数和新的日期。教师打开同一节点核对作答与复习计数，从节点进入课程公告发布讲评。
5. 切换为同专业但未加入该测试班的学生，确认图谱和新发布材料不可访问。课堂展示使用测试账号与演示数据。

## 回归验收

| 场景 | 通过条件 |
| --- | --- |
| 图谱编辑 | 本班教师可保存和重载。跨班、重复、自指、循环、无效页码与过期版本均被拦截。 |
| 视频与入库 | 课件页受课程权限校验。重复导题只保留一份，导入时绑定的知识点可追溯。 |
| 作答与复习 | 作答和复习命中同一知识点。复习次数增长，原得分保留。作业答案继续按提交次数解锁。 |
| 角色与名单 | 班内学生只看到自己的练习与排程。教师汇总只包含当前有效名单，移出后该学生的历史记录仍可查询。 |
| 删除、复制与持久化 | 删除视频或资料后显示来源不可用。复制后的班级拥有独立 ID。重载可恢复图谱和已保存的学习事件。 |

可运行 `python -m unittest discover -s tests -p test_ai_quiz_actions.py -v` 复现接口验收。自动化测试用预制的课件页和已保存题目核对关联与权限。真实视频提取及 AI 结果审核按课堂脚本验证。

2026-11-26 的隔离回归共 174 项通过，其中视频集成测试使用实际 FFmpeg。浏览器核对了教师保存关系与讲义、学生从图谱进入章节练习、错题按知识点筛选，以及教师查看对应班级统计。

## 下一阶段
