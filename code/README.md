# 知学 · 智慧学习平台 Demo

本地 Python 服务 + 原生 HTML/CSS/JavaScript。支持教师发布与维护课程、布置带截止时间的作业、查看/导出成绩册、发送公告，学生学习与答题、自动评分、持久化学习记录，以及师生上传课程视频并提取课件图片、PDF 和音频。可通过科大讯飞将录音转为文字稿，并选择课件截图、演讲文字或两者一起交给 DeepSeek 生成课程总结、单选练习；答题后还可生成错题解析与学习分析 HTML，在新标签页阅读并下载。

## 启动

需要 Python 3.10+。Windows 双击 `run.bat`，或者在本目录执行：

```powershell
python run.py
```

启动脚本会创建本目录的 `.venv`，使用 **清华大学 PyPI 镜像**安装依赖和 FFmpeg：

```text
<项目虚拟环境的 Python> -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

首次安装需要联网；之后依赖未变化时直接启动，不会重复安装。安装失败不会写入成功标记，重新运行会再次尝试。服务只监听本机，默认地址 `http://127.0.0.1:8765`，占用时自动尝试后续端口，以启动窗口的地址为准。保留启动窗口，按 `Ctrl+C` 停止。

```powershell
python run.py --check                 # 准备并检查依赖后退出
python run.py --no-browser --port 8800 # 指定端口，不自动打开浏览器
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

macOS/Linux 的虚拟环境 Python 位于 `.venv/bin/python`。

## 教师教学空间与作业流程整理（2026-11-11）

教师从工作台的“进入教学空间”，或顶部“课程与作业”进入。各页保留同一门课程的上下文，提供固定栏目：**课程设置 / 章节与资料 / 课程题库 / 作业管理 / AI 出题与分析 / 成绩册 / 课程公告**。课程编辑不再把所有设置和表单同时铺开；资源创建、编程题与归档操作按需展开。

### 创建作业与准备具体题目

1. 在“作业管理”点击“创建作业”，第一步新建本次作业独立使用的题目，填写题干、选项、标准答案与解析。
2. 题目仅保存到本次作业；课程题库中面向自主练习的题目不提供选入作业的入口。
3. 第二步填写标题、说明、截止时间、提交次数，以及可选的作答时限和迟交规则。可以先保存无截止时间的草稿，发布前补齐截止时间。
4. 第三步预览题目与标答，确认发布。每次提交立即显示得分，答案与解析在该学生用完全部提交次数后开放。
5. 已有学生提交后不能更改题目和提交次数。作业列表可查看提交明细、分析学生作答、提醒未交或归档。

编辑器在当前标签页 SessionStorage 暂存独立题目和规则，不保存密钥；草稿与已发布作业由服务端持久化。

### AI 出题与分析的固定入口

- 课程内“AI 出题与分析”提供固定入口，页面明确区分准备题目和分析学生作答。
- 出题复用已有的视频 → 提取 → 课程总结流程，展示本人材料的就绪状态与缺少步骤，并可直接打开材料管理。点击生成后显示实际出题进度；每份生成结果可预览题干、四个选项、答案和解析。
- 教师审核并勾选后，将题目导入指定课程章节，供学生自主练习；作业需另行创建独立题目。导入不调用 AI；相同来源版本与题目重复导入会返回已有题目，不重复新增；之后可以在题库修改或停用。
- 导入接口为 `POST /api/courses/{course_id}/questions/import-ai`，接收 `job_id`、`quiz_id`、`chapter_id`、`question_ids`。服务端只读取当前教师自己的已校验题目文件，检查课程归属、源版本与目标章节。保存失败回滚，不接受浏览器替换题干、答案或解析；学生课程接口不返回私人来源信息。
- 分析入口同时出现在作业提交明细、成绩册的有成绩单元格、AI 页课程作答列表和既有学习记录中。分析页可返回原课程的 AI 页面。现有密钥、权限与结果缓存规则继续生效。

验证：教师模块 11 项 HTTP 集成测试通过（本轮新增 4 项），覆盖选中题目导入后的作业计分、权限与版本检查、重复导入、保存失败回滚、重启和停用题目的发布检查。浏览器已验证手动创建 → 跨章节选题 → 预览发布 → 学生提交 → 教师查看与分析入口，以及模拟 AI 响应的审核导入、草稿刷新恢复。AI 验收未调用付费服务。macOS 全量回归发现原有 Python 判题资源限制错误 `current limit exceeds maximum limit`，直接运行改版前 main 的执行器也可复现；本次未修改判题执行器。

## 本轮更新：教师端内容管理、作业、成绩册与公告（2026-11-10）

教师端从“建课 → 发布 → 看统计”扩展为可维护、可布置任务、可导出成绩、可沟通的教学闭环。无需新增依赖，停止旧服务后重新运行 `python run.py` 即可；旧数据自动补齐 `assignments`、`assignment_attempts`、`announcements` 字段。

### 课程内容管理

- 课程标题、简介、分类、难度、学时可在课程编辑页修改；课程支持 **复制**（生成草稿副本，重新生成章节/题目/资源 ID，不复制提交）、**归档**（学生不可访问，历史提交保留）与 **恢复**。
- 章节支持重命名、上移/下移、删除。删除仍有题目或资源的章节时，必须选择迁移到其他章节，或确认级联删除；课程至少保留一个章节。
- 学习资源支持编辑名称、类型、章节、讲义正文和代码示例，也支持删除。
- 单选题支持编辑题干/选项/答案/解析/章节/知识点、上移/下移，以及 **停用**（`status: retired` 软删除）和恢复。停用题目不会下发给学生，历史提交和错题快照仍保留；教师端可见并恢复。
- Python 编程题同样支持编辑标题/描述/章节、排序、停用与恢复；判题用例保持不变。
- “学生视角预览”通过 `GET /api/courses/{id}/preview` 返回可查看题库标答的学生预览结构，隐藏判题用例和停用题目，教师在发布前即可检查学生端排版。

### 作业与截止时间

- 新增 `assignments`：标题、说明、章节和独立的 `questions`、开放/截止/关闭时间、最多提交次数、作答时限、迟交策略（允许迟交天数与每天扣分）、按提交次数解锁答案的规则和状态（草稿/已发布/归档）。
- 学生从作业页或课程章节进入作业，服务端在开始作答时记录 `assignment_attempts`；提交时校验时间窗、次数、时限和迟交扣分。提交记录新增 `assignment_id`、`attempt_id`、`late`、`late_days`、`penalty_percent`、`raw_score`、`duration_seconds`。
- 每次作业提交立即显示得分，用完全部提交次数后才向该学生开放答案、解析、错题和 AI 分析；教师端始终可查看完整作答。
- 教师可查看每份作业的已交/未交人数、平均分、迟交人数和未交名单，并一键向未交学生发送公告提醒。
- 作业以单选题为范围；当前页面为每份作业单独创建题目，编程题作业尚未接入。

### 成绩册与导出

- 教师“成绩册”按 **学生 × 已发布作业** 展示成绩，可切换“最近一次/最高分/第一次”取值，按章节、学生提交状态筛选；包含平均分、提交项数和迟交标记。
- `GET /api/teacher/gradebook?course_id=...` 返回矩阵；`GET /api/teacher/gradebook.csv?course_id=...` 导出带 UTF-8 BOM 的 CSV，Excel 直接打开中文不乱码。
- 点击学生姓名进入个人详情：四维雷达、作业情况、练习提交、错题与掌握情况；接口只允许教师查看本人课程范围内的学生。
- 成绩册统计课程面向专业学生及已参与学生；只有已发布作业的提交计入作业成绩。未发布作业的教学班没有作业成绩。自主练习、错题复习和 Python 编程题保留在学习记录与学情分析中，不计入成绩册。

### 公告与提醒

- 新增 `announcements`：标题、正文、受众（全体/未提交/需关注）、置顶、收件人快照和已读记录。
- 收件人由服务端按课程范围和提交情况计算，不接受浏览器上传名单；未提交/需关注受众在发送时生成快照。
- 学生端导航显示未读红点，工作台展示最新公告，公告页支持“标记已读”和“全部标记已读”；教师端显示收件人数、已读人数并可删除公告。
- 作业管理页的“提醒未交”会复用公告能力，向未交学生发送作业提醒，不调用外部邮件服务。

### 接口、文件与验证

- 内容管理：`PATCH/DELETE /api/courses/{id}`、`POST /api/courses/{id}/duplicate`、`POST /api/courses/{id}/restore`、`GET /api/courses/{id}/preview`、章节/资源/单选题/编程题的 `PATCH`/`DELETE` 与 `reorder`。
- 作业：`/api/courses/{id}/assignments`（教师 CRUD/发布/发布成绩/提醒/提交情况）、`/api/assignments`（学生列表）、`/api/assignments/{id}`、`POST /api/assignments/{id}/start`；提交仍走 `POST /api/courses/{id}/submissions`，额外携带 `assignment_id` 与 `attempt_id`。

## 本轮更新：AI 一键出题（2026-11-10）

在视频学习页面成功生成总结后，点击 **一键出题**。系统使用同一个 DeepSeek 密钥，读取已保存总结对应的材料，生成 **10 道单选题，每题 4 个选项**。练习新标签页先显示进度，JSON 校验成功后显示与课程单选题一致的作答界面；若浏览器拦截新标签页，完成后可点击 **打开练习**。

### 来源与生成规则

- 出题来源由后端读取成功保存的总结决定：**仅 PPT**只发送截图，**仅演讲文字**只发送转写稿，**PPT + 演讲文字**发送两类材料。页面临时切换总结选项不会改变出题依据；总结重新生成失败时，沿用保留的旧总结来源。
- 复用总结的图片缩放、段落编号和材料大小限制；不发送总结 HTML 或原始音频，不读取未选择的文字或图片内容。生成前检查总结和所需材料是否存在；缺少前提时按钮置灰，并显示操作指引。
- 使用 DeepSeek 的 JSON 输出模式。按项目已有单选题结构接收 `id`、`chapter_id`、`knowledge_point_id`、`text`、`options`、`answer`、`explanation`；`answer` 必须是从 0 开始的整数索引。外层结构为 `{"title":"练习标题","questions":[…]}`。
- 本地严格校验恰好 10 题、每题 4 个不同的非空选项、唯一题目 ID 和题干、答案索引、解析、字段及长度。不合格或截断 JSON 不保存、不渲染，不用本地编造的题目补齐；题目文字按普通文本转义显示。
- 同一份总结重复点击复用已经保存的有效练习，不重复扣费。成功更新总结后，再次点击会按新来源重新出题；生成失败保留旧练习，仍可通过“打开练习”访问。出题期间不允许删除任务或修改总结，避免材料来源变化。

### 作答、进度与故障提示

题目完整作答后，在浏览器本机判分（每题 10 分），显示总分、对错、所选答案、正确答案与逐题解析；支持重新作答，当前标签页刷新保留已选答案。题目 JSON 保存到任务目录，刷新或重启后可重新打开。学生作答还会由本地服务校验并保存到本人学习记录，可点击 AI 分析；视频自测独立于教师发布的课程成绩与错题本。

主页面和练习页都显示准备材料、等待 AI、校验与保存的进度。等待 API 时使用不定进度条和已等待时间，不虚构模型完成百分比。密钥缺失可使用现有浏览器输入弹窗；密钥错误、余额不足、限流、网络超时、JSON 格式错误、材料丢失或保存失败均提供中文提示，可手动重试。刷新可恢复生成状态；服务重启将进行中的任务标为中断，不自动再次调用付费 API。

接口 `POST /api/jobs/{id}/quiz` 发起生成，`GET /api/jobs/{id}` 获取 `quiz` 状态和 `quiz_options` 前提，`GET /api/jobs/{id}/quiz` 读取校验后的练习。全部按当前登录账号验证所有权，课程资源分享不会开放他人的 AI 练习。删除整个任务时同步删除练习 JSON。

- **课程创建与编辑**使用专业单选，同一课程用不同教学班覆盖不同专业。Python 分为软工、人工智能与计科三个班，因此三个专业都可学习。改变班级专业后按新范围访问，真实历史提交与错题保留。
- **教师雷达图**在每位学生的条目中独立展开与折叠，另有“全部展开”“全部折叠”。教师画像覆盖本人课程面向的各专业学生，不再按教师专业筛选。
- **学生学习画像**通过导航“学习档案”的“画像与课程进度”或工作台快捷入口打开，包含课程参与、练习积极、平均成绩、答题掌握四维雷达。接口只返回当前学生的画像；教师视图与学生视图使用同一计算方法，但课程统计范围可能不同。
- **错题与复习**合并到一个页面，可切换今日复习、全部错题、已掌握，并按课程和知识点筛选。逐题提交后保留答案、解析和下次复习日期，标记已掌握后退出队列。旧的错题、复习页面地址仍可打开统一页面。
- **界面**统一更新了导航、课程封面 SVG、章节讲义、画像、复习卡片和小屏布局。无需 Node.js 或前端构建工具。

## 学生与教师的视频提取

双方工作台均提供“上传与提取视频”入口：

1. 选择或拖入视频，确认后上传到本机项目目录。
2. 选择细致/均衡/精简模式，查看上传、识别、导出进度；支持取消。
3. 完成后预览课件页面，下载 JPG 压缩包、图片式 PDF 和 MP3 音频；点击“课件 PPTX → 导出”下载每页一张截图的演示文稿。
4. 教师可以在课程编辑页刷新提取结果，将完成的任务关联为课程资源；学生可直接打开课件。
5. 对含音轨的视频，点击“生成录音文字稿”，通过讯飞识别录音；完成后可新标签页查看文字稿，下载 HTML 或 TXT。
6. 选择“PPT + 演讲文字”“仅 PPT”或“仅演讲文字”生成课程总结；仅 PPT 不要求先转写。查看准备材料、等待 DeepSeek、检查与保存的进度，完成后在新标签页阅读或下载 HTML。
7. 总结保存成功后点击“一键出题”，沿用该总结的材料来源，生成 10 道单选题；在新标签页作答并自动判分。

视频提取只在本机运行，不需要 API Key、Node.js 或显卡；可选的 AI 总结需要互联网和 DeepSeek 密钥。每个任务输出位于 `data/jobs/<任务 ID>/`：

```text
job.json       # 账号归属、提取与总结状态、页码、时间和 API 用量（不含密钥）
slides/        # 去重后的原尺寸 JPG
slides.pdf     # 图片式课件 PDF
slides.pptx    # 点击导出成功后出现；每页一张原始截图的演示文稿
slides.zip     # 全部 JPG
audio.mp3      # 第一条音轨；无音轨时不生成
summary.html   # 点击生成且成功后才出现；DeepSeek 返回的静态总结网页
quiz.json      # AI 一键出题校验通过后保存；10 道单选题、解析及来源信息
transcript.html # 讯飞录音转写成功后，由本机程序排版的静态文字稿
transcript.txt  # UTF-8 BOM 格式的录音转写原文
```

源视频的上传副本在任务完成、失败或取消后删除，原始视频不受影响；生成资料可在刷新或重启后继续下载。保存位置由浏览器下载设置决定。

适合 PPT/讲义占主要画面且有稳定停留的录像，使用 FFmpeg 缩略图流、帧差和感知哈希提取稳定页面。重复页面保留首次结果；动画、鼠标和摄像头可能造成多页或漏页，请核对预览。最多 600 页、单文件上限 8 GB，同一服务一次处理一个视频。无稳定页面时使用间隔截图并提示；无音轨时仍会生成图片和 PDF。

**提取产物是 JPG/PDF/MP3，并支持进一步导出图片式 PPTX；幻灯片中的文字与图表仍属于截图。已接入基于截图、演讲文字或两者结合的 AI HTML 总结、网页内的折叠自测题，以及讯飞录音转文字；将 AI 题目导入课程题库并计分尚未接入。**

`VIDEO_DEMO_FFMPEG` 可指定 FFmpeg 路径，也可放入 `bin/ffmpeg.exe`；否则优先使用 PATH，再使用依赖中的 FFmpeg。`VIDEO_DEMO_DATA` 可更改任务目录，账号和学习数据随之存放在该目录的上级目录。

## 讯飞录音转文字

使用科大讯飞[极速录音转写大模型 HTTPS 接口](https://www.xfyun.cn/doc/asr/speedTranscription/API.html)，与 `experiments/xfyun_speed_transcription.py` 的真实实验使用相同流程。

讯飞需要 **APPID、APIKey、APISecret 三项**，不能仅配置一个 API Key。在 Windows“编辑账户的环境变量”中设置：

| 用户变量或启动进程环境变量 | 内容 |
| --- | --- |
| `XUNFEI_APP_ID` | 讯飞应用的 APPID |
| `XUNFEI_API_KEY` | 该应用的 APIKey |
| `XUNFEI_API_SECRET` | 该应用的 APISecret |

也兼容实验脚本使用的 `XFYUN_APP_ID`、`XFYUN_API_KEY`、`XFYUN_API_SECRET`。每次启动转写时读取，顺序为当前进程环境、Windows 用户变量、Windows 系统变量；同一来源优先使用 `XUNFEI_*`。在服务启动后新增的用户变量可直接读取，修改已由进程继承的变量则需要重启服务。

如果缺少任一项，点击“生成录音文字稿”时会弹出三项密码输入框；也可点击“设置 / 更换讯飞凭据”。输入的凭据仅保存在当前账号的本次登录会话中，刷新可继续使用；退出登录、会话失效或重启服务后不可继续使用，不写入项目文件或浏览器存储。手动输入的完整凭据优先于环境变量。

操作流程：

1. 登录学生或教师账号，打开视频工作台，上传并提取视频。
2. 含音轨的视频完成后显示“生成录音文字稿”，点击后检查凭据。
3. 本机把 MP3 转为 16kHz、16bit、单声道 WAV，上传讯飞并提交识别任务。只有点击转写后才上传音频；调用可能消耗讯飞额度。
4. 页面显示格式准备、上传、提交、识别、排版保存的阶段进度。讯飞不返回准确百分比时，使用等待动画和已等待秒数；可刷新或切换页面，保持本地服务运行即可。
5. 成功后点击“查看文字稿 ↗”，在新标签页查看带时间戳的分段原文；可以从工作台或阅读页下载 HTML、TXT。HTML 内含绿色主题和移动端、打印样式，下载后可离线阅读，无需再次调用 AI。

识别原文由讯飞返回，本机仅转义、分段和排版，不使用 DeepSeek 补写或润色；准确率需要结合原视频核对。单文件遵循接口的 5 小时、500MB 限制（500MB 指转换后的 WAV）；30MB 以上使用分片上传。无音轨时不显示转写入口。

文字稿与原视频任务同属当前账号，其他账号即便能访问已发布课程的课件也无法读取文字稿。最近任务可重新打开文字稿；删除任务会同时删除 HTML、TXT。转写过程中禁止删除任务，防止后台重新写出文件。

凭据无效、权限/额度不足、网络故障和结果解析失败均显示提示并弹窗。课件和原 MP3 保留，可重试。已有讯飞任务 ID 的失败或中断任务会继续查询原任务，避免重复创建识别任务；默认单次查询等待上限 10 分钟。尚未收到任务 ID 时发生提交超时，需留意讯飞控制台任务状态与额度后再尝试。

验证：新增 12 项离线测试覆盖环境变量、会话凭据、权限隔离、HTML 转义、重复点击、失败恢复、任务删除和磁盘错误；完整回归 54 项通过。2026-11-03 使用 `example.mp4` 进行了真实浏览器验收：上传视频、缺少凭据弹窗、输入凭据、讯飞识别、刷新恢复、新标签页阅读、HTML/TXT 下载、移动端和跨账号隔离均通过；得到 41 段课程录音文字。首次整体回归出现两次 Windows 本机 HTTP 连接中止（WinError 10053），重新运行全部测试后通过，完整日志保存于验收目录。验收数据在 `.demo-test/transcription-ui/`，不修改正式账号和任务。

## DeepSeek 课程总结

### 配置密钥

Windows 可在“编辑账户的环境变量”中新增用户变量 `DEEPSEEK_API_KEY`，值为自己的 DeepSeek API 密钥。也可以在 PowerShell 中配置用户变量：

```powershell
[Environment]::SetEnvironmentVariable("DEEPSEEK_API_KEY", "填入你的密钥", "User")
```

仅希望当前启动窗口使用时：

```powershell
$env:DEEPSEEK_API_KEY = "填入你的密钥"
python run.py
```

登录并进入工作台、视频页等页面后，会自动检查密钥。未配置时弹出密码输入框，可直接粘贴密钥并点击“使用此密钥”，也可选“稍后设置”继续使用本地提取。生成前会再次检查；结果页提供“设置 / 更换 API 密钥”入口。

后端按 **当前登录会话手动提交的密钥 → 服务进程环境变量 → Windows 用户变量 → Windows 系统变量** 的顺序取首个非空值。用户变量在点击时读取；若修改了服务已继承的旧环境变量值，应重启服务。macOS/Linux 使用进程环境变量。

环境密钥不会返回浏览器。手动输入的密钥只保存在当前登录会话的后端内存，不写入账号/任务文件、LocalStorage 或 SessionStorage；提交后清空输入框。刷新页面可继续使用，退出登录或重启服务后清除，其他账号和登录会话不能借用，也不会出现在教师统计或学生画像中。

### 使用与进度

1. 登录学生或教师账号，打开“视频提取”，上传视频并完成本地预处理。已有的成功任务也可使用。
2. 在“选择总结依据”中选择一种方式，再点击“生成课程总结”。新任务默认选择“PPT + 演讲文字（推荐）”；如果只需要课件总结，可以选择“仅 PPT”，无需等待转写。调用会使用 DeepSeek API 额度。
3. 准备材料时显示截图张数或文字段数；等待 API 时显示动态进度条和已等待时间；收到结果后显示检查、保存，成功后到达 100%。等待 API 时不伪造完成百分比。
4. 点击“查看课程总结 ↗”，新标签页显示 DeepSeek 生成的概览、知识点、来源、易混点及折叠自测题。页面显示当前保存总结所依据的材料，内容应结合原课核对。
5. 生成期间可刷新或离开页面，但应保持 Python 服务运行。生成结果和状态保存在任务目录；重启后重新登录即可查看。服务中断的生成任务会标记为“已中断”，可以重试。

三种方式的前提与实际发送内容：

| 方式 | 生成前提 | 发送给 DeepSeek 的材料 |
| --- | --- | --- |
| PPT + 演讲文字（推荐） | 本地预处理完成、课件截图可用、录音转文字完成且文字稿可用 | 提取的 JPG + 录音文字稿 |
| 仅 PPT | 本地预处理完成且课件截图可用 | 仅提取的 JPG，不读取或发送文字稿 |
| 仅演讲文字 | 本地预处理完成、录音转文字完成且文字稿可用 | 仅录音文字稿，不读取或发送截图 |

这里的 PPT 指视频中提取的课件截图。原视频、MP3、PDF 均不发送给 DeepSeek。三种方式使用不同提示词：课件方式按页码/时间引用画面；文字方式按文字段落引用、标注疑似识别错误，不生成图片；组合方式结合课件与讲解，区分来源并指出冲突，不编造逐段与截图的对应关系。

条件未满足时，相应选项及生成按钮置灰。鼠标悬浮、键盘聚焦或尝试点击会显示缺少的步骤，“去完成本地预处理 / 去生成录音文字稿”可定位到相关入口；不会提前调用 API。转写完成后选项自动解锁。后端同样校验任务和实际材料文件，直接调用接口也不能绕过前提。无音轨的视频只能使用“仅 PPT”。

更新项目代码后，需要关闭原启动窗口并重新运行 `run.bat`，再打开新启动窗口显示的地址、刷新并登录；仅刷新浏览器不会更新已经运行的 Python 后端。若课件已提取但旧服务没有返回总结前提状态，页面会明确提示重启服务，提供“重启服务后重新检查”，不会再误导用户重新上传或预处理。已保存的课件与任务会保留。上传和取消任务的响应也包含前提状态，保持页面状态一致。

正在生成时重复点击不会重复调用 API；同一服务一次生成一个总结。任务详情和总结仅允许任务所属账号访问。教师发布的课件 PDF 等学习资源仍供课程面向专业的学生阅读，学生不能据此打开教师的私人任务和总结。

### 最近任务与总结管理

- **账号隔离**：“最近任务”只列出当前账号创建的任务；任务详情、总结查看/下载/生成/删除及任务删除接口都验证账号归属，修改 URL 不能访问其他账号的任务。
- **删除任务**：任务行提供“删除任务”。确认后移除 `data/jobs/<任务 ID>/` 下的任务 JSON、课件 JPG/PDF/PPTX/ZIP、音频、总结、AI 练习和临时文件，同时清理课程中的对应资源引用。原始视频、其他任务、课程练习、学生成绩、错题本和教师统计保留。处理中的任务不能删除：视频可先取消，AI 总结、AI 出题、录音转写和 PPTX 导出需等待完成。
- **下载总结**：首次生成完成、从最近任务重新打开、总结独立查看页，均提供下载入口。下载的是单个 UTF-8 HTML，内嵌引用的 JPG，离线打开或删除原任务后仍能查看截图。
- **删除总结**：结果页的“删除总结”只移除总结 HTML、总结临时文件及任务中的总结状态；保留课件和音频，可再次生成。
- **重新生成**：可先切换总结方式，再点击标明所选方式的“重新生成”。确认后重新调用 DeepSeek 并消耗额度。旧版仍可查看和下载，新结果检查通过后才替换旧文件；失败时保留旧版及旧版来源标记。
- 最近任务可手动刷新，切回页面时也会刷新；任务和总结查看保持新标签页方式。

### 错误处理与实现范围

- 缺少密钥、密钥失效、余额不足、权限不足、限流、服务异常、网络故障、超时、截图丢失或存储失败，均提供中文错误说明。生成失败和进度连接失败会在浏览器弹窗，同时保留页面提示。错误不覆盖已有 JPG/PDF/MP3，可在排除原因后重试。
- 后端固定使用 `https://api.deepseek.com/chat/completions` 和支持图片输入的 `deepseek-flash`，按选择发送 Base64 JPG 和/或文字。每张发送副本最长边缩至 1600 像素，原图不修改；最多 600 张，文字稿上限 1 MiB，总请求限制在 45 MiB 内，超过时提示拆分，不会静默截断。连接/读取超时为 180 秒，网络恢复后不会自动重复付费请求。
- 总结正文由 **DeepSeek 实际返回**。若请求失败、内容截断或 HTML 不合格，显示失败，不使用本地模板或其他模型冒充生成结果。
- 只接收静态 HTML/CSS；禁止脚本、事件属性、外部资源等内容，并以独立 CSP 限制页面。在线查看时添加平台下载/管理链接，将截图转换为受权限校验的地址；下载时内嵌截图。AI 总结正文不改写。
- 当前只生成 HTML 总结；可使用浏览器打印功能另存 PDF。网页自测题不自动计入课程成绩或学习记录。
